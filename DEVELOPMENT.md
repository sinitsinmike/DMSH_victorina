# Музыкальная викторина ДМШ

Статическое приложение без внешних зависимостей. Работает в подпапке GitHub Pages.

## Локальный запуск

```sh
npm run build
npm run dev
```

Откройте http://localhost:4173. Проверка логики: `npm test`.

## Первая подборка

В `teacher.html` создайте подборку, выберите MP3 и заполните названия. Экспортируйте JSON. Загрузите новые MP3 в `MP3/`, JSON — в `quizzes/`. Текущие MP3 предназначены для теста звука: учебных подборок пока нет.

Индекс каталога и библиотека аудио формируются автоматически в GitHub Actions. Некорректные подборки пропускаются с диагностикой; конфликт идентификаторов останавливает публикацию. Отсутствующий MP3 исключает подборку из каталога до загрузки записи.

## GitHub Pages

Workflow `.github/workflows/pages.yml` тестирует приложение, создаёт индексы и публикует только файлы сайта. Если GitHub не разрешит автоматическое включение Pages, в Settings → Pages выберите Source: GitHub Actions и повторно запустите workflow Publish music trainer. Предполагаемый адрес: https://sinitsinmike.github.io/DMSH_victorina/.

Учётных записей, сервера результатов и офлайн-загрузки нет. Черновики хранятся только в браузере; локальные MP3 не сохраняются после закрытия страницы. Совместимость со школьными браузерами High Sierra и физическими Android/iOS требует проверки на устройствах.
